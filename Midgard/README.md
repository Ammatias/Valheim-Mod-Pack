# Midgard

[Скачать Midgard-Modpack.bat](https://github.com/Ammatias/Valheim-Mod-Pack/releases/download/midgard-2026.11.24.2/Midgard-Modpack.bat) · [Полный комплект и контрольные суммы](https://github.com/Ammatias/Valheim-Mod-Pack/releases/tag/midgard-2026.11.24.2)

Положите батник рядом с `valheim.exe` в отдельной чистой папке игры, откройте Steam и запустите батник. Он установит сборку и запустит Valheim. При следующих запусках он проверит обновления.

В ZIP включены BepInEx, моды и начальные настройки. Устанавливать загрузчик отдельно не требуется.

[Посмотреть все файлы сборки (233)](FILES.md) — загрузчик, моды, ресурсы и настройки с размерами и SHA-256.

Распакованные файлы доступны в [BepInEx/](BepInEx/): [моды и ресурсы](BepInEx/plugins/), [конфиги](BepInEx/config/), [загрузчик](BepInEx/core/). Корневые файлы загрузчика находятся рядом с этим README. На странице любого файла доступно отдельное скачивание через **Download raw file**.

## Моды

ValheimPlus, Jotunn, Warfare, Monstrum, PlanBuild, PlantEverything, PlantEasily, InventoryPlus, BetterArchery, ComboSpear, TrashItems, AutoServerPassword, ModSettings, Badgers Shading Overhaul и Skies.

Настройки в `BepInEx/config` сохраняются. Дополнительные моды из управляемых каталогов удаляются при обновлении. Для Helheim используйте другую папку игры.
