# Midgard

[Скачать Midgard-Modpack.bat](https://github.com/Ammatias/Valheim-Mod-Pack/releases/latest/download/Midgard-Modpack.bat)

Положите батник рядом с `valheim.exe` в отдельной папке игры для Midgard, откройте Steam и запускайте игру через батник. Обновлятор загрузит необходимые файлы из Releases.

Версия первого комплекта: 2026.11.24.1, 233 файла в 20 компонентах. Состав: ValheimPlus, Jotunn, Warfare, Monstrum, PlanBuild, PlantEverything, PlantEasily, InventoryPlus, BetterArchery, ComboSpear, TrashItems, AutoServerPassword, ModSettings, Badgers Shading Overhaul и Skies.

Полные файлы модов находятся в [Releases](https://github.com/Ammatias/Valheim-Mod-Pack/releases), а не в истории Git. Локальные конфиги и сохранённые пароли сохраняются; посторонние DLL из управляемых каталогов удаляются. Helheim/Yggdrasil устанавливайте в другую папку игры.
