# Valheim Mod Pack

Клиентские сборки модов для **Midgard** и **Helheim** с установкой и обновлением через батник. Для игры нужны Valheim для Windows и Steam.

## Установка

1. Подготовьте чистую папку Valheim. Для каждой сборки используйте отдельную папку игры.
2. Скачайте батник выбранной сборки и положите его рядом с `valheim.exe`.
3. Откройте Steam и запустите батник. Он скачает сборку, проверит файлы и запустит игру.

Для последующих запусков используйте тот же батник. Если требуется обновление или восстановление файлов, он скачает полный ZIP. Если установленные файлы совпадают с текущей версией, повторная загрузка не нужна. Перед обновлением закройте игру.

## Файлы сборки

У каждой сборки свой Release с тремя файлами:

- ZIP — моды, загрузчик BepInEx и начальные настройки.
- BAT — установка, обновление и запуск игры.
- `SHA256SUMS.txt` — контрольные суммы ZIP и BAT.

Архив вручную скачивать и распаковывать не требуется: это делает батник. В папках репозитория находятся инструкции, батники и `latest.json`, по которому выбирается версия сборки. Полные комплекты хранятся в Releases.

## Настройки и совместимость

Существующие настройки в `BepInEx/config` сохраняются; отсутствующие конфиги добавляются. Параметры с синхронизацией приходят с сервера при подключении. Миры, персонажи и сохранённые пароли сохраняются.

Каталоги `BepInEx/plugins`, `core` и `patchers` приводятся к составу сборки, поэтому добавленные вручную моды в этих каталогах будут удалены при обновлении. Не смешивайте Midgard и Helheim в одной папке. Версия сборки должна соответствовать серверу.

Состав модов указан на страницах [Midgard](Midgard/) и [Helheim](Helheim/). Сторонние моды принадлежат своим авторам и распространяются с их лицензиями.
